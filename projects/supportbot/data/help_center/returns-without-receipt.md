# Returning a gift or an item without a receipt

If you received an item as a gift, you can return it for store credit. You need the gift receipt or the order number.

Without a receipt or order number, we can look up the order by the buyer's email address. If we cannot find it, we offer store credit at the lowest recent price.

Store credit is issued as a Northwind gift card and never expires.
