# Exchanging for a different size or colour

You can exchange an item for a different size or colour within 30 days of delivery. Exchanges are free, and we ship the new item as soon as the carrier scans your return.

Each item can be exchanged once. If the new size still does not fit, you can return it for a refund.

If the size you want is out of stock, we refund the item instead.
