# Partial refunds

A partial refund returns part of an order total. We issue partial refunds when you return only some items from an order, or when an item arrives with a missing part.

The refund covers the price of the returned items. Original shipping costs are not refunded unless the return is our mistake.

You can request a partial refund through chat with your order number and the items involved.
