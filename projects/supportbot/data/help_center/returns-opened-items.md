# Can I return opened items?

Yes, you can return items in opened packaging as long as the item itself is unused. Keep all parts, manuals and accessories in the box.

Camping stoves, fuel canisters and water filters can only be returned if they have never been used, for safety reasons.

Tents and sleeping bags that have been set up indoors to check the fit are fine to return. Please fold them back into their bags.
