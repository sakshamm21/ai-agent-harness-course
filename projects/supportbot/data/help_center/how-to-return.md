# How to return an item

To start a return, open the Orders page, choose the order, and select Return items. Pick the items and a reason.

We email you a prepaid return label. Print it, attach it to the box, and drop the box at any UPS location within 14 days.

You can also return items in person at any Northwind Outfitters store. Bring your order number.
